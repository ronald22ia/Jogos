PLAYZONE — SITE DE JOGOS

Como abrir:
1. Extraia o arquivo ZIP.
2. Abra a pasta "arcade_mobile".
3. Toque/clique duas vezes em "index.html" para abrir no navegador.
4. No celular, você pode abrir o index.html pelo navegador usando um gerenciador de arquivos.

Arquivos:
- index.html: estrutura do site.
- style.css: visual, cores e adaptação para celular.
- script.js: catálogo e funcionamento dos minijogos.

Jogos incluídos:
Cobrinha, Jogo da memória, Clique rápido, Adivinhe o número,
Pedra-papel-tesoura, Desafio de matemática, Acerta a toupeira e Sorte no dado.

Observação:
O site funciona sem servidor e não precisa instalar bibliotecas. A fonte personalizada pode depender de internet; se estiver offline, será usada uma fonte alternativa do aparelho.
